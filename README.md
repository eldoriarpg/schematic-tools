# Schematic Tools

Schematic Tools is an add-on for [Schematic Brush Reborn 3](https://github.com/eldoriarpg/SchematicBrushReborn).
It binds saved brushes to items, so players can paste with them without setting up a brush themselves.
Tools can be limited by permission and by usages, and can be changed after they were handed out.

## Requirements

- Paper 1.21.11 or newer
- Java 25
- Schematic Brush Reborn 3 and FastAsyncWorldEdit

## Documentation

See [docs.eldoria.de](https://docs.eldoria.de/schematic-brush-reborn/tools) for installation, commands, permissions and configuration.
